# Blockchain Trust Validator Selection

This repository contains the source code, machine learning models, analysis notebooks, and documentation for the ML-based Trust Validator Selection project.

## Repository Structure

- `src/`: Core source code including the final blockchain simulation (`final_blockchain_simulation.py`) and trust scoring module (`get_trust_score.py`).
- `models/`: Trained machine learning models (e.g., `trust_classifier_FINAL.pkl`).
- `data/`: Datasets and logs used for training and testing the models.
- `notebooks/`: Jupyter notebooks containing data analysis (e.g., `role3_analysis.ipynb`).
- `docs/`: Comprehensive project documentation, literature review, and presentation materials.
- `tests/`: Unit tests for the modules.

## Setup

Install the required dependencies using:

```bash
pip install -r requirements.txt
```

## Running the Simulation

Execute the final blockchain simulation:

```bash
python src/final_blockchain_simulation.py
```
